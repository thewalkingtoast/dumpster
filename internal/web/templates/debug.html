    WebSocket 5 pings 1s apart, echoes sent frames
    
      
    
      
    
          How to use?
          
    Opens a socket and holds it open. Type a line and press Enter: each
            line is sent as one text frame, recorded on this dumpster's row, and echoed
            straight back at you. The five pings arrive one a second and websocat answers
            them without printing anything — that is the socket proving it is alive
            while the terminal looks idle.
    
          
    One frame from a pipe, then exit:
    
          
    
          
    A frame carrying bytes that are not valid UTF-8 — those are kept
            byte-for-byte as base64:
    
          
    
          
    A binary frame whose bytes are valid UTF-8 — an emoji, say
            — is shown as text instead, because that is what it is.
    
          
    
          
    These end by hanging up rather than closing politely,
            so its row says client hung up without a close frame. That is the pipe
            finishing, not a fault — the frame itself arrived and was recorded.
    
          
    No websocat? The browser console does the same:
            let ws = new WebSocket('wss://<host>/d/<id>/ws'); ws.onopen = () => ws.send('hello')
